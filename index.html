พื้นที่ข้อมูลเงินเดือนร่วม

บัญชีที่เจ้าของอนุญาตจะดูและแก้ไขข้อมูลเดือนเดียวกันได้ทันที โดยใช้ข้อมูล Firebase เดิมของเจ้าของ ไม่ต้องย้ายหรือคัดลอกข้อมูล

อนุญาตผู้ใช้อื่น

ให้ผู้ใช้ใหม่ส่ง UID จากหน้าเดียวกันนี้มา แล้วเพิ่ม UID เพื่อให้สิทธิ์ดูและแก้ไข

จัดการผู้ใช้

Admin สร้างชื่อผู้ใช้และรหัสผ่านให้สมาชิกได้ สมาชิกไม่ต้องกรอกอีเมล และจะเข้าถึงข้อมูลเงินเดือนเดียวกันตามสิทธิ์

เชื่อมบัญชีสมาชิกที่มีอยู่แล้ว

บัญชีทั้งสามมีอยู่ใน Firebase Authentication แล้ว กดเชื่อมสิทธิ์ทีละบัญชี ไม่ต้องสร้างซ้ำ ไม่เปลี่ยนรหัสผ่านหรือข้อมูลเงินเดือน ตรวจสอบ UID ให้ตรงกับ Firebase Authentication ก่อนกด

สร้างเฉพาะสมาชิกโดย Admin • ใช้ชื่อผู้ใช้บนทุกอุปกรณ์ • ไม่ใช้ Cloud Functions

สมาชิก

หากสมาชิกเข้าสู่ระบบไม่ได้ ให้กด “ตรวจ/ซ่อมสิทธิ์” ของบัญชีนั้นก่อน ไม่ต้องลบหรือสร้างบัญชีใหม่

รีเซ็ตข้อมูลเดือนนี้?

การรีเซ็ตจะคืนค่ารายการของเดือนที่เลือกเท่านั้น เดือนอื่น ๆ และปีอื่น ๆ จะไม่ถูกลบ

⧉ คัดลอกข้อมูลจากเดือนก่อน

ข้อมูลในเดือนปลายทางจะถูกแทนที่ทั้งหมด (รายการเดิม จำนวนเวร และยอดเงิน) แต่ข้อมูลเดือนต้นทางจะไม่เปลี่ยนแปลง
